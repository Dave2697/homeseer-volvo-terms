# HomeSeer Volvo Integration — Terms and Conditions **Last updated: 28 October 2026** ## 1. About this application HomeSeer Volvo Integration is a personal home automation project that connects the owner's Volvo vehicle to their private HomeSeer home automation system. It retrieves vehicle energy information, such as battery charge level, estimated electric range, charging status and charger connection status, to display this information on private dashboards. ## 2. Personal use This application is intended for personal use by the vehicle owner. It is not a commercial service and is not offered for resale. ## 3. Vehicle data The application accesses only the Volvo vehicle data permitted by the authorisation granted to it. Data is used to support the owner's home automation and vehicle monitoring functions. The application owner does not intend to sell vehicle data or share it with third parties. ## 4. Availability and accuracy Vehicle data availability depends on Volvo's services, network connectivity and the vehicle's ability to report information. Data may be delayed, incomplete or temporarily unavailable. The application is provided on an as-available basis. It must not be relied upon for safety-critical decisions. ## 5.
